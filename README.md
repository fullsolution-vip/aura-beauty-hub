# Full Solution Web

A premium beauty and skincare e-commerce platform built with TanStack Start.

## Live Demo

**Live URL:** https://aura-beauty-hub.pages.dev

## Development

```bash
npm install
npm run dev
```

## Deployment (Cloudflare Pages)

Automatic deployment on push to main via GitHub Actions.

Manual deploy:

```bash
npm run build
npx wrangler pages deploy dist/client
```

## Tech Stack

- TanStack Start
- React 19
- TanStack Router
- Tailwind CSS v4
- Radix UI Components
