# Full Solution Web

A premium beauty and skincare e-commerce platform built with TanStack Start.

## Live Demo

**Live URL:** https://fullsolution-vip.github.io/aura-beauty-hub/


## Development

```bash
npm install
npm run dev
```

## Deployment

The site is deployed automatically to GitHub Pages on push to main. To deploy manually:

```bash
npm run build
npm run preview
```

## Tech Stack

- TanStack Start
- React 19
- TanStack Router
- Tailwind CSS v4
- Radix UI Components
